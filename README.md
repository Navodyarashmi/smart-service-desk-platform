# Smart Service Desk Platform

A production-style IT service desk application for employees, technicians, and administrators.

## Project Status

The project is currently in the initial setup stage. Application features have not yet been implemented.

## Planned Technology Stack

### Frontend

- React
- Responsive user interface
- REST API integration
- Dashboard charts

### Backend

- Java 21
- Spring Boot
- Spring Security
- JWT authentication
- REST APIs
- Automated tests

### Database

- PostgreSQL
- Database migrations

### Development and Deployment

- Git and GitHub
- Docker and Docker Compose
- GitHub Actions
- Cloud deployment

## Planned User Roles

- Employee
- Technician
- Administrator

## Planned Core Features

- User registration and login
- Role-based authorization
- Ticket creation and assignment
- Categories and priorities
- Ticket status workflow
- Comments and attachments
- Audit history
- Notifications
- Dashboards and charts
- REST API documentation
- Automated testing
- Demo accounts
